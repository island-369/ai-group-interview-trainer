# AI 群面陪练（AI Group Interview Trainer）

> 用多智能体模拟一场"无领导小组讨论"群面：AI 面试官 + N 个性格各异的 AI 候选人陪你练，练完给出证据化的复盘报告。

- **版本**：v0.1（设计阶段）
- **日期**：2026-10-24
- **当前状态**：M1 完成 + 真实模型校准通过（DeepSeek flash，L1 拟真度达标）；语音方案（06）已定稿，下一步语音 V1（级联管线）

---

## 一句话产品定义

**AI 群面陪练 = 多智能体拟真对局 + 证据化评估反馈 + 可调难度训练场**

针对校招/社招中淘汰率最高、又最难自主练习的"群面"环节，让求职者随时组一局 6~8 人的无领导小组讨论，AI 候选人会抢话、会沉默、会结盟、会集火，练完按 8 个维度拿到逐句带证据的评分报告。

## 核心概念速览

- **群面流程**：宣题 → 独立阅读 → 个人陈述 → 自由讨论 → 总结陈词 → 复盘
- **导演-演员架构**：DirectorAgent 全局控制发言节奏与剧情冲突，CandidateAgent 专注角色扮演，InterviewerAgent 控场
- **8 个评估维度**：内容贡献、逻辑结构、沟通表达、倾听回应、团队协作、领导影响、情绪抗压、角色与时间管理
- **4 档难度预设**：新手陪跑 / 标准校招 / 拟真大厂 / 地狱压力
- **实现节奏**：M0 骨架 → M1 文本 MVP → M2 拟真化（打断/剧情）→ M3 语音
